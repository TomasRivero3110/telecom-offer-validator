# telecom-offer-validator
Python tool for validating telecom product catalog offers using SQL queries and automated Excel reports.
The project executes SQL queries against an Oracle database, validates relationships between telecom offers and bonuses, and generates Excel reports to assist catalog auditing processes.

## Features

- Execute SQL queries against Oracle databases
- Validate telecom offer structures
- Detect configuration inconsistencies
- Export automated Excel validation reports

## Tech Stack

- Python
- SQL
- Oracle Database
- Pandas
- OpenPyXL
